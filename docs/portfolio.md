# BookHaus portfolio brief

## Positioning

BookHaus is a full-stack personal reading companion that demonstrates secure API design, relational domain modelling, external-service integration, derived analytics and a polished responsive React experience.

## CV bullets

- Built a full-stack reading platform with React 19, Spring Boot 3 and PostgreSQL, covering book discovery, personal libraries, reading progress, custom shelves, journals, quotes, annual goals and insights.
- Designed a JWT-secured REST API with user-scoped ownership, Flyway-managed relational migrations and an Open Library provider boundary, supported by focused service and integration tests.
- Delivered a responsive portfolio-grade interface with accessible states, reusable components, production profiles and deployable Vercel, Render and PostgreSQL configuration guidance.
